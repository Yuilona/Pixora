# Pixora

跨平台截图/贴图工具（Windows / macOS / Linux），功能对标 Snipaste，并提供其没有的**长截图（滚动截图）**能力。

> 🚧 项目处于早期开发阶段。

## 技术栈

C++20 · Qt 6 (Widgets) · CMake + vcpkg · OpenCV（图像拼接）
